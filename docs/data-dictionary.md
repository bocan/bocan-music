# Data dictionary

Generated by `Scripts/gen-data-dictionary.py` (`make data-dictionary`); do not edit the tables by hand. Curated content lives in `docs/data-dictionary-notes.json` and is merged in on regeneration.

**How to read it.** *Written by* and *read by* come from a grep of the Swift sources outside migrations and tests (a file counts as a writer if it assigns the property, passes it as an init argument, or names the column in an INSERT / UPDATE). They are leads, not verdicts. GRDB record files are listed once per table rather than as writers, and single-word column names (`id`, `name`, `title`) are not grepped at all because they match everything. *Traces to* is the ADR or issue the column serves; a bare migration number means nobody has reviewed the row yet. A blank *written by* cell on a populated table is a dead column and needs an issue (see #414).

Schema discipline rules are in `CLAUDE.md`.
